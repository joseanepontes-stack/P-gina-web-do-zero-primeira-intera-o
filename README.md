# 💻 Meu Primeiro Blog

Projeto de um blog simples sobre programação e tecnologia, desenvolvido com HTML e CSS.

## 📖 Sobre o projeto

Este projeto apresenta uma página inicial de blog com um artigo contendo:

- 🧠 Imagem temática sobre tecnologia e educação
- 📝 Título da publicação
- 👤 Nome do autor
- 💬 Texto introdutório
- ❤️ Botão de curtida
- 👍 Botão de reação

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
